About

Network Speed Test measures your internet connection right from your browser or phone — on Wi-Fi, mobile data (4G/5G) or Ethernet.

What is measured

  • Download / Upload — throughput over several parallel connections; the first 25% of each phase (ramp-up) is excluded.
  • Ping — median round-trip time to the nearest test server while the line is idle.
  • Jitter — how much ping varies between consecutive samples.
  • Loaded latency — ping measured while downloading/uploading. A big jump means bufferbloat (laggy calls & games when someone is downloading).
  • Request loss — share of latency probes that failed or timed out (an HTTP-level stand-in for packet loss).
  • Connection details — network type, public IP, ISP, location and test server.

Test servers: Cloudflare's global edge network (speed.cloudflare.com). Results are stored only on this device.
